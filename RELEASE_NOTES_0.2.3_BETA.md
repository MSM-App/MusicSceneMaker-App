# MusicSceneMaker 0.2.3 Beta 1 — 24.10.2026

**Windows x64 · тестовая версия.** Сборка из отдельной копии локального Dev 0.2.2 Beta с исправлениями 22–24 октября. Исходная 0.2.2 сохранена.

## Главное — редактор каждой сцены MiniMax H3
- Полный редактор открывается двойным кликом по сцене в монтажном столе (либо через кнопку инспектора).
- Четыре вкладки: **Промпт**, **Генерация**, **Образы**, **История**. Отдельные настройки сцены и черновик до сохранения.
- Ручная правка русского текста и пересборка промпта, ручной EN-промпт, вставка меток героев и управление составом сцены. Для нового режиссёра изменения состава проходят через пересборку постановки.
- Для одной сцены можно менять параметры генерации (включая шаги, LoRA) независимо от соседних; дополнительных LoRA теперь можно выбрать из внешних папок и с других дисков без копирования. Некоторые внешние папки становятся доступны ComfyUI после перезапуска движка.
- В непрерывных дублях показаны фрагменты и варианты перезапуска нужного фрагмента/его продолжения. Сохранение не запускает рендер автоматически.
- Заметны индикаторы ручной настройки/LoRA/промпта и переход между сценами.

## Прогресс операций и экспорт
- Реальные полученные/всего байты при скачивании моделей, этапы подключения, проверки SHA-256, предупреждение при отсутствии новых сведений.
- Экспорт музыкальных клипов: этапы, реальный процент кодирования FFmpeg, примерное оставшееся время, остановка, сохранение прогресса при переходе между страницами.
- Аппаратное кодирование NVIDIA NVENC для H.264/H.265, выбор программного кодирования; корректное завершение FFmpeg при остановке/закрытии.
- Экспорт Stories: индикация этапов, NVENC/CPU, остановка сборки и общий статус. Коды протестированы; живую приёмку UI до конца ещё не провели.

## Другие изменения
- Работа режиссёра с героем и костюмом по конкретной сцене: сохранение лица/возраста/телосложения при смене одежды по погоде и ситуации.
- Уточнения логики Continuity и видеопромптов, усовершенствования обработки аудио и связи текста песни с сюжетом.
- LTX 2.5 I2V: улучшения задания кадров (включая 16:9), исправления ряда параметров VAE tiled; качество требует живого сравнения.
- Исправления части интерфейса настроек, скачивания моделей и индивидуальных параметров генерации.

## Известные ограничения
- Редактор сцены проверен в DEV в UI без GPU; перегенерация с индивидуальными настройками и проверка сгенерированного графа всё ещё требуют live A/B. Смена состава героев/готовых роликов имела инциденты и требует осторожности, особенно на важных исходных проектах; создавайте копии.
- Варианты A/B, полноценная история общего дубля, отдельные параметры каждой сцены внутри одного общего дубля и некоторые другие функции редактора ещё не реализованы.
- Новая полоса экспорта Stories ещё не принята полностью вживую.
- Latent Upscale MiniMax H3 **не признан исправленным**: повышение разрешения само по себе не даёт ожидаемой детализации лиц/движения.
- Известны старые сбои некоторых Rust-тестов; чистая установка на другом компьютере и полный GPU E2E в этом релизном проходе ещё не подтверждены.
- Установщик без цифровой подписи. ComfyUI, модели и расширения требуют отдельной установки/загрузки; приложение ориентировано на Windows x64.

**Важно:** исправления качества генерации не следует считать доказанными без живых рендеров. Эта версия предназначена для тестирования.
