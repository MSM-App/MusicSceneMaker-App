# MusicSceneMaker 0.2.1 Beta — изменения 19–20 октября 2026

Публичное тестовое обновление локальной AI-студии музыкальных клипов для Windows x64. Это подробная история изменений на основе ежедневного журнала разработки, а не только последних правок при сборке.

## Режиссёр и вокальное исполнение MiniMax H3

- Исправлена логика «кто поёт»: при постановке учитываются отметка исполнителя в карточке и явная видимость именно его лица. Присутствие персонажа в списке сцены, тень, силуэт, голос за кадром или слова о пении сами по себе больше не должны разрешать липсинк. Отражение с реально видимым лицом допускается.
- Уточнены правила режиссёра, критика и пересборки сцен: неправильные фразы вроде «другой герой поёт» отбрасываются, а слушатели должны оставаться с расслабленными губами. Правила применяются к классическим одиночным сценам, Light Director и ContinuityChain нового H3 Director.
- Если вокальная строка пересекает две сцены, допустимые исполнители определяются отдельно для каждого фрагмента, а не по единственному кадру посередине.
- Добавлена обработанная звуковая дорожка vocal_gate для MiniMax: вне разрешённых окон вокал выключается для видеомодели. Итоговый клип по-прежнему получает полную музыку; тишина в драйвере нужна только для предотвращения ложного движения рта.
- В ContinuityChain по умолчанию используется выделенный вокальный стем вместо всей песни; для инструментальной музыки предусмотрена отдельная логика. Это должно снизить ложный липсинк под скрипку и другие инструменты, но не гарантирует его устранения, если Demucs ошибочно выделит инструмент в вокальный стем.
- Исправлена привязка голоса: пол голоса из карты вокала учитывается при выборе поющего героя; устаревшая ручная привязка к уже удалённому персонажу не должна блокировать новый выбор. Если подходящего певца нет, насильно назначать голос другому полу не следует.

## Карточки героев, референсы и непрерывность сцен

- Уточнено создание многоракурсных карточек героя: крупный портрет лица, ростовые виды и аккуратное сохранение головы, причёски и головного убора. Для MiniMax в итоге возвращён лист около 2 Мп. Наличие специальной экспериментальной закраски лица в процессе разработки проверялось, но затем она полностью **отключена**: видеомодель переносила чёрный квадрат на героя. Эту отменённую экспериментальную функцию не считаем преимуществом релиза.
- Улучшено описание персонажа по утверждённой картинке: зрительная модель извлекает короткие отличительные черты, но в финальном референсном промпте MiniMax изображение остаётся главнее спорных словесных описаний. Уточнены правила нечеловеческих персонажей, теней и отражений.
- Проверена передача картинок в ComfyUI без подмены файла или перепутанных Subject/Picture. Однако сохранение лиц у H3 всё ещё **не гарантировано**; требуется сравнение рендеров при одном seed.
- В ходе экспериментов режим размера входного референса несколько раз переключался между match и max. В текущих шаблонах музыкального MiniMax H3 установлен max; в двух шаблонах Stories MiniMax остался match. Такое различие не рекламируется как подтверждённое улучшение качества.
- Добавлена версия отпечатка continuity v3 с учётом режима размера референса, чтобы при изменении режима пересоздавать несовместимые латентные чанки, а не смешивать контекст предыдущей генерации. Дополнительная проверка согласованности константы и шаблонов остаётся открытой.

## Генерация, скорость и новые модели

- Добавлен **необязательный MiniMax H3 Latent Upscaler**: оригинальная 3D-модель либо LMS v0.1, промежуточные целевые размеры 16:9 и 16:10 вплоть до 2560×1600, числовое количество шагов 1–8 и разбиение латентов (автоматически / без разбиения / вручную). Разрешения исходного видео не меняются, для продолжения чанка используется оригинальный latent.
- Графы H3 переведены на встроенный ComfyUI **BlockSparseAttention (sol-attn, tau 1.3)** вместо прежней связки внешних Sage/Sol patch-нод. Режим настраивается в интерфейсе.
- При выбранной модели **MiniMax H3 Singularity** автор промптов и режиссёр получают инструкцию WarmBloodAban по композиции, камере, идентичности, материалам и непрерывности. На обычную ConvRot это правило не распространяется.
- Эксперименты со скоростью 15-секундного ролика: Original Upscaler 2 шага — 6:19, LMS 1 шаг — 5:10, прямое Full HD — 8:23. Это **не строгое A/B-сравнение**: менялись и модель, и число шагов. Сам апскейл генеративный и может изменить лица, детали или даже действия.

## Проверки и известные ограничения

- После адресных изменений вокала был проведён Rust-прогон: 3325 passed, 11 ранее известных failed, 66 ignored, 2 теста Triton исключены после зависаний. Проверки нескольких наборов сцен/референсов прошли. Общий набор нельзя объявлять полностью успешным.
- Для нового апскейлера пройдены четыре адресных теста, Rust и фронтенд успешно компилируются. Собран Windows x64 NSIS release-установщик. Полный GPU-регресс новой опубликованной версии и установка на чистом компьютере ещё не проведены.
- Продолжаем исследовать нестабильное сохранение внешности, физику отражений, ложный липсинк, ошибки Critic/continuity, шум и заметные стыки видео. LTX 2.5 не изменялась перечисленными исправлениями MiniMax.
- В установщик не включены большие веса моделей и весь дополнительный AI-стек; понадобится подготовленное локальное окружение. Установщик не подписан сертификатом.
