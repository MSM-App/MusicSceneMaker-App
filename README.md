# MusicSceneMaker 0.2 Beta

**Первая публичная тестовая версия MusicSceneMaker для Windows x64.**

MusicSceneMaker — приложение для создания музыкальных AI-видеоклипов: от сценария и построения сцен до генерации кадров, видео и экспорта. Основные генеративные процессы работают локально на компьютере пользователя.

## Что уже есть

- Музыкальные клипы на MiniMax H3: сценарий, сцены, герои, референсы и генерация видео.
- Локальный пайплайн с ComfyUI и экспорт готового ролика.
- Инструменты работы с героями, музыкальными фрагментами и продолжением сцен.
- Экспериментальные инструменты генерации изображений и музыки.

## Что пока «В разработке»

- **LTX 2.5 для музыкальных клипов** — сценарист и генерация требуют дальнейшего тестирования.
- **Stories / Reels** — могут быть заметны стыки, разрывы звука и нарушения непрерывности действия.
- **Киносцены** — пока недоступны.
- **Online Director** и отдельные музыкальные функции — экспериментальные.

## Перед установкой

Это **ранняя бета для добровольного тестирования**, а не проверенный стабильный релиз. Полный сценарий установки на чистую Windows пока не подтверждён. Мы выпускаем программу именно для того, чтобы обнаруживать и исправлять ошибки на разных компьютерах.

- Требуется **Windows x64**. Для локальной AI-видеогенерации нужна **NVIDIA GPU**; тяжёлые модели могут требовать много VRAM и RAM. Тесты разработки проводились, в частности, на RTX 4090 24 ГБ.
- EXE **не содержит многогигабайтные AI-модели**. После установки может понадобиться загрузка ComfyUI, FFmpeg, нужных моделей и настройка отдельных компонентов.
- Не все зависимости пока устанавливаются автоматически. Часть действий может потребовать ручной настройки.
- Сохраните свои проекты и материалы перед обновлением или экспериментами.

## Какие ошибки возможны

Ошибки установки или первого запуска, отсутствие зависимостей, сбои в загрузке моделей, неправильные герои или локации, неудачная синхронизация пения, заметные переходы между сценами и проблемы со звуком — всё это ещё исправляется.

**Если программа не установилась, не открывается или что-то не работает — пожалуйста, сообщите.** Опишите Windows, видеокарту, выбранный режим, шаги, ожидаемый результат, фактическую ошибку и приложите скриншот/лог без секретов. Будем править по мере поступления отчётов.
