# MusicSceneMaker 0.2.1 Beta 2 — тест установки (21.10.2026)

**Windows x64 · промежуточная тестовая версия.** Исправления по первым сообщениям бета-тестировщиков 0.2.1. Тяжёлые модели и ComfyUI не входят в установщик — загружаются отдельно.

## Исправлено и улучшено
- Установка ComfyUI Portable: встроенный декодер 7z/LZMA2 вместо несовместимого системного Windows tar.exe. Поддерживается ранее скачанный проверяемый архив comfyui.part; не требуется установленный 7-Zip.
- Перенос хранилища: повторное использование уже перенесённых идентичных файлов; конфликтные файлы не затираются, временная .staging не копируется; проверка содержимого вместо проверки только размера.
- Предупреждения о недостатке свободного места, в том числе когда перенос выполняется внутри одного диска.
- Модели по умолчанию размещаются в каталоге моделей выбранного ComfyUI; старые несуществующие пути к ядру игнорируются, явно выбранный существующий внешний ComfyUI сохраняется.
- Индикатор этапов установки ядра/моделей, таймер, визуальная обратная связь кнопок. Реальный процент используется только при скачивании, во время распаковки показывается анимация без фиктивных процентов.
- Вместо [object Object] показывается подробное сообщение об ошибке, ошибки установки и переноса пишутся в журнал.
- Старые NVIDIA, включая GT 730, обнаруживаются средствами Windows при недоступном nvidia-smi. Обнаружение GPU не означает совместимость с CUDA или генерацией MiniMax.
- Перед созданием проекта предупреждение о недостающих компонентах выбранного режима; можно заранее писать сценарий и перейти к установке позже.
- Нормальная Windows-иконка MSM (размеры 16–256 px).

## Что проверили до публикации
- Tauri NSIS x64: успешная release-сборка EXE и установщика.
- Rust: 13 тестов загрузчика, включая распаковку тестового 7z под именем .part; 26 тестов хранилища; Stories: 15 тестов; TypeScript/Vite: сборка прошла.
- **Ограничения:** настоящий архив ComfyUI около 1,9 ГБ на чистом Windows-компьютере, слабый ПК с GT 730, весь установочный мастер и полная загрузка моделей пока не проверены. Общий npm test пока имеет 10 несовпадений устаревшего test-clean-base.mjs; это не полный PASS.
- Эта бета не подтверждает GPU-рендер на GT 730: карта не подходит для современных моделей H3/LTX.
